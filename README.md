# chenxi-career-hub

武汉西安央国企优先的个人求职信息站 —— 349 条机会与线索，打开即用。

## 👉 点击这里打开网站

**[https://wangwang041030-svg.github.io/chenxi-career-hub/](https://wangwang041030-svg.github.io/chenxi-career-hub/)**

> 也可以直接点仓库页面右侧 **About** 区域里的 **Website** 链接，效果相同。

## 这个站点能做什么

- **机会库**：内置 349 条招聘公告与企业线索（数据导出于 2026-11-19），按「收藏优先、其次央国企」排序。
- **搜索与筛选**：支持按单位、岗位、材料方向搜索，按城市（武汉 / 西安 / 其他）、单位性质（央企 / 国企）、信息类型（招聘公告 / 企业线索）筛选。
- **重点与进度**：★ 标记重点关注，下拉选择投递状态（待了解 / 准备投递 / 已投递 / 笔试 / 面试 / 已获 Offer / 未通过 / 已结束），可切到「投递进度」视图统一查看。
- **原文跳转**：有链接的记录显示「查看原文 ↗」，点击直接跳到招聘公告原始页面。
- **备份**：右上角「导出备份」下载 JSON，「导入备份」在另一台电脑恢复。收藏和投递状态保存在**当前浏览器**（localStorage），换设备或清缓存前请先导出。

## 更新数据

1. 在网站右上角点「导出备份」，得到 `晨曦求职备份-YYYY-MM-DD.json`。
2. 把该文件交给维护者，将其记录写入 `index.html` 里脚本开头的 `const seeds=[...]`，提交推送即可。
3. GitHub Pages 会自动重新发布（约 1 分钟）。

## 说明

- 招聘公告与企业线索分开标注；**线索不代表当前有岗位**，学历、专业代码、截止日期一律以原文为准。
- 站点为单文件静态页面（`index.html`），无后端、无需登录，可直接在 Chrome 打开或离线保存。
